# Twin - AI Morning Brief

Daily AI news brief generated by Twin.

- Short version is delivered to WhatsApp every morning at 07:30 (Europe/Helsinki).
- Long version is published here via GitHub Pages.

Structure:
- `index.html` - landing page, loads the latest brief and the archive
- `briefs/latest.html` - most recent brief body
- `briefs/YYYY-MM-DD.html` - archived editions
- `briefs/index.json` - archive index (newest first)

Published at https://juntunen-ai.github.io/Twin/
